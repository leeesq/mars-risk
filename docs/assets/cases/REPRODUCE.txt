公开站点展示规模为 18,000 行；其他规模仅用于 API/语义回归。
先在已安装兼容 MARS 及 docs 依赖的 Python 环境解压，不要求解压目录是 git 仓库。
在解压目录执行：

python task_cases.py --case all --rows 18000 --seed 20261001 --output-dir reproduced

也可在当前 MARS 源码仓库执行 docs/snippets/task_cases.py；--repository-root /path/to/mars-risk 可显式记录仓库来源。

--case 1..7 按需运行；6/7 需要已有 score-cross 和 policy 快照，不重复计算宽表。
--phase consume 在新进程只加载快照；--phase finalize 更新摘要、来源和 ZIP。

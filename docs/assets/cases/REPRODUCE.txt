# Home Credit 2018 共享案例复现

本包包含全量真实特征/原始标签的聚合统计；APPLY_DATE 是确定性模拟日期。
保存报告的查询可使用兼容 MARS 0.0.28 及依赖，在任意解压目录运行（无需 CSV）：
python task_cases.py --phase consume --output-dir .

实际重算需安装本次修改后的当前源码（含规则无标签评估修复），并自行取得 Kaggle 三文件；不随本包发布：
python task_cases.py --case all --data-dir /path/to/raw_data --output-dir reproduced
也支持 --train-csv、--test-csv、--columns-description-csv。
固定 seed=20261001，目标分区人数30000；输入指纹与真实分区见 preparation-summary.json。
Train 用于拟合与 PSI，Val 用于规则筛选，Test/OOT 固定规则独立复核；July 无标签。
--phase finalize 只收集已计算产物；ZIP 使用显式允许清单。
ReportSnapshot 不恢复原始宽表或任意分析器；只加载可信报告。

# 性能、内存与规模

优化计算、转换、展示、保存、相关性表示或 Agent 执行预算时读取。
先核对当前源码与 benchmarks，优化不能改变业务口径。

## 投影与物化

- 先投影必要特征和角色列，再转换／物化，复用 mars.compute 的共享能力。
- 核心计算优先 Polars／表达式与共享算子；Pandas 限于明确后端或渲染边界。
- 批次覆盖当前与基准转换、聚合及必要日期计算，跨批次只保留小统计表。
- 不为一张展示表增加额外宽表副本，不保存跨会话全局缓存。
- 优化前后验证指标公式、缺失处理、样本范围、已表现分母及最终参数一致。
- 复用已计算结果；报告读取不重新分箱、聚合或调用领域分析。

## 展示与保存

全量结果保留与展示范围分开；先筛选／排序／投影／分页，再转 Pandas／JSON。
图表、相关性矩阵、JSON 与 HTML 明确规模边界和省略说明。
保存按既有契约逐表处理，不全报告转大 JSON，不为保存保留额外宽表。
字符输出预算与计算预算分别记录，不承诺精准 token／CPU／内存硬限额。

## 相关性

关注 O(p²)，使用现有紧凑存储／分块能力，避免长特征名重复展开为无界明细。
筛选与报告复用同一表示、方法、缺失策略、阈值和事件证据。
不为了展示或 Agent 消费重算另一种相关性，不能把 WOE／raw、Pearson／Spearman 混用。
展示矩阵先限制候选集合；完整证据仍可按公共查询继续读取。
验证状态、符号、对角值、并列顺序和筛选结论等价，不只测运行耗时。

## 模型分交叉

复用固定分段与联合聚合，先小统计表聚合再展开标签。
保留分数方向、缺失／未匹配箱、基准、已表现分母、权重、金额与币种。
边际从计数／权重相加再计算，不能平均格子坏率或混加不同 target 人数。
保存后回放使用聚合证据与声明能力，不伪装为原样本重算。

## 执行预算与缓存

默认参数解析后统一校验，显式与省略 features 同等受限。
预算只约束内置 Agent 新计算，不强制限制普通公共分析 API 或已有大报告查询。
预检查当前／基准行数、有效特征、分组／日期、分箱及趋势／明细估算规模。
先 O(1) 检查，再投影角色列轻量统计；类别分箱考虑基数，避免 n_bins 低估。
超预算返回维度、实际／估算值、上限和缩小建议；不暴露原样本、不静默裁剪或抽样。
默认值写明基准／典型场景依据和估算限制，不假装是精确资源测量。
先复用已有会话报告。若缓存同参计算，键含数据身份／版本、基准、工具与全部解析参数，
有容量／生命周期；防外部修改污染，不保留额外宽表副本或跨会话全局状态。

## 测量

先通过结果等价与小型规模回归，再按任务需要运行独立 benchmark。
记录环境、版本、数据规模、参数、耗时、峰值／增量内存与测量限制。
大任务分阶段／分进程，避免环境和前序任务影响结论；禁止虚构性能数字。

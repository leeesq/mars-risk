# 公共报告与外部消费

新增／修改报告字段、查询、业务元数据、证据、上下文预算或持久化时读取。
普通用户接入见 docs/user-guide/external-agents.md；这里约束 MARS 工程实现。

## 公共结果是主要接口

- 新结果优先接入既有 Report 契约，结构化结果是主接口，导出是能力之一。
- 目录说明表名、粒度、字段类型、单位、实际参数、状态、诊断和限制。
- 不只描述 HTML／Excel／plot，不为外部 Agent 新建平行数据体系。
- 外部消费者直接调用公共 API；mars.agent 是消费者，不独占查询和保存。
- 未计算、失败、未表现与统计上未定义不等于业务上没有风险。

## 元数据与实际参数

英文字段名是稳定身份；中文名、来源、描述和特征值单位由 feature_metadata 传递。
不重命名原始宽表，不在每个箱／日期行重复长文本；重名检索返回候选英文键。
区分调用方 business_context 与实际 parameters，未提供信息保持 unknown。
标签定义、表现窗口、样本范围、切片、金额／币种、分数方向不按列名猜测。
计算单位与特征值单位独立；字段更名或改变语义须明确影响、更新受影响消费者与迁移。

## 查询、上下文与证据

先筛选／排序／投影／分页，再转换展示或 JSON；保持原表后端与全量结果。
分页记录 total_rows／returned_rows／omitted_rows、下一页和可重放引用。
证据绑定持久 report_id、表与有效查询参数，不混淆会话句柄与持久身份。
最终序列化上下文预算包括目录、参数、元数据和省略说明；字符不是 token。
预算裁剪保留完整字段／行、明确原因及继续查询入口；不足时返回明确错误。
不先全表转 JSON／Pandas 再 head，不用输出预算代替新计算预算。
浮点非有限数、null、0 复用既有序列化规则，不自行编码第二种语义。

## 快照及边界

使用既有 .marsreport（manifest + Parquet）机制，记录格式版本、身份、语义与来源。
不能用 pickle 替代公共分析快照，不要求 Modeling 或会话才能保存。
根据报告类型声明恢复后通用展示、领域回放及计算边界。
ReportSnapshot 不恢复任意分析器、模型、原始宽表或原报告全部方法。
新增／修改保存能力验证“保存 → 新进程加载 → 查询 → 展示／导出 → 证据引用”，
无需原数据、原分析器或原会话；同时检查元数据、状态、schema、顺序与身份。
核心文件格式变化需版本与迁移说明；不能套用暂停模块豁免任意破坏公共报告。

## 专用消费

相关性邻居、诱导子矩阵、筛选决策复用公共查询与同一计算表示，不另算 Agent 矩阵。
模型分交叉保存固定分段、格子、边际及能力；策略回放读取已聚合证据，
不伪装为重新访问个体样本，不能声称支持改变原样本或任意新聚合维度。
金额／权重／表现分母、缺失与 invalid 箱、基准及分数方向随结果保存。
专用函数验证通用快照消费路径，不另造并行序列化或查询框架。
